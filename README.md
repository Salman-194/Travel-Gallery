# Travel Gallery

A responsive travel gallery website built using HTML and CSS Grid.

## Features
- Responsive layout for mobile, tablet and desktop
- CSS Grid layout
- Six destination cards with images
- Featured destination card
- Responsive images

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Media Queries

## Destinations
1. Goa
2. Ooty
3. Jaipur
4. Munnar
5. Kochi
6. Shimla

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open Index.html using Live Server.
