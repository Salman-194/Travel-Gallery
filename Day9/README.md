# HackGeniX – Day 9 & Day 10 Projects
## Project Overview

This project was completed as part of the HackGeniX Web Development Internship.

It covers DOM manipulation, JavaScript events, form handling, and browser local storage through practical projects.
## Day 9 – Travel Gallery

### Features

- Dynamic gallery cards created using JavaScript.
- Used an array of objects to store travel destination details.
- Used DOM manipulation to create and display elements.
- Used querySelector and querySelectorAll to select HTML elements.
- Used textContent and classList to update page content and styles.
- Used createElement() and append() to add elements dynamically.

## Day 10 – JavaScript Events and To-Do App

### Features

- Used addEventListener() to handle user interactions.
- Handled form submission using the submit event.
- Used preventDefault() to control form submission.
- Added form validation with error messages.
- Used event delegation to handle dynamic elements.
- Stored tasks using browser localStorage.
- Used JSON.stringify() and JSON.parse() to save and retrieve task data.
- Tasks remain available after refreshing the page.
